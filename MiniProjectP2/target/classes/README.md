# Student Management System

## Features
- JWT Authentication
- Role-based Authorization (USER / ADMIN)
- CRUD APIs
- Exception Handling

## Tech Stack
- Spring Boot
- Spring Security
- JWT
- MySQL

## API Endpoints
- POST /auth/login
- GET /students
- DELETE /students/delete/{id}

## How to Run
1. Clone repo
2. Run application
3. Use Postman / Swagger
